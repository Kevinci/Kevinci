## 👨‍💻 About Me

I'm **Kevin Imig**, a developer focused on frontend engineering, UI/UX, full-stack development, and open-source software.

I enjoy building practical tools that solve real engineering problems — from dependency-free PDF generation to better navigation in large data tables and type-safe HTTP integrations.

* 🧩 **Open Source:** Building and maintaining reusable developer tools and npm packages.
* 🎨 **Frontend & UI/UX:** Creating usable, polished interfaces and reusable components.
* 🟦 **TypeScript & JavaScript:** Developing libraries with a focus on developer experience and maintainability.
* ⚙️ **Full-Stack Engineering:** Connecting frontend experiences with robust backend functionality.
* 🚀 **Developer Experience:** Making complex workflows simpler, faster, and more pleasant to use.

My philosophy is simple: build useful things, keep improving them, and share them with the community.

Generate PDFs without Chromium, native binaries, or runtime dependencies.

* 🌐 Node.js, Bun, Deno, browsers, and edge/serverless runtimes
* 🧰 Designed for straightforward integration into JavaScript applications

### 📊 Table-Minimap

**A minimap for navigating large HTML tables.**

Inspired by code-editor minimaps, Table-Minimap helps users navigate wide or lengthy tables without being tied to a particular frontend framework.

* 🧭 Navigate large tables more easily
* 🧩 Framework-agnostic integration
* 🎯 Designed to improve usability in data-heavy interfaces

### 🔗 HTTP-QUERY Toolkit

**A TypeScript library family for type-safe HTTP QUERY workflows.**

A set of complementary packages for building typed queries, managing filters, and integrating query functionality into React and Next.js applications.

| Package                                                                                    | Purpose                                                           |
| ------------------------------------------------------------------------------------------ | ----------------------------------------------------------------- |
| [`@kevincii/http-query-client`](https://www.npmjs.com/package/@kevincii/http-query-client) | Type-safe client with retries, caching, fallbacks, and pagination |
| [`@kevincii/http-query-core`](https://www.npmjs.com/package/@kevincii/http-query-core)     | Framework-agnostic query-building engine                          |
| [`@kevincii/http-query-react`](https://www.npmjs.com/package/@kevincii/http-query-react)   | React hooks and provider integration                              |
| [`@kevincii/http-query-next`](https://www.npmjs.com/package/@kevincii/http-query-next)     | Next.js integration and server-side support                       |

### 🛡️ TypeScript Profanity Filter

**Configurable text filtering for modern applications.**

A TypeScript library that identifies potentially offensive text and returns segments suitable for UI rendering.

* 🌍 English and German support
* 🔎 Configurable language registration
* 🧩 Text-segment output for frontend interfaces
* 🤖 Optional AI-assisted checking
